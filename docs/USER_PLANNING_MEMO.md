# 사용자 기획 방향 메모

> 이 문서는 지금까지 대화에서 **사용자가 직접 선택하거나 요청한 방향만** 정리한다. 구현자가 추가로 제안한 세부 기능이나 디자인 판단은 넣지 않는다.

- 과제는 제공된 `README.md`, JSON 계약/스키마/fixture의 가이드라인을 준수하며 진행한다.
- 처음 검토한 달러 환율 대신 **비트코인 데이터**를 주제로 사용한다.
- 실제 데이터는 공개적으로 조회 가능한 비개인 동적 데이터여야 한다.
- 단순히 빠르게 끝내기보다 **손이 더 가더라도 과제에 맞춘 완성도 높은 결과물**을 지향한다.
- GitHub 계정은 이미 보유하고 있다.
- 배포 방식은 아직 익숙하지 않다.
- 완성 후 코드를 기초 수준에서 다시 읽었을 때, "이 코드가 이렇게 동작하고 에러는 이런 형식으로 나오는구나"를 따라갈 수 있는 구조를 원한다.
- 스택 대안 중 **B안**을 선택해 제작한다.
  - Next.js
  - TypeScript
  - Neon PostgreSQL
  - Drizzle ORM
  - Vercel
  - GitHub
- 제작 후에는 사용자가 정한 기획 방향만 별도 메모로 남긴다.
